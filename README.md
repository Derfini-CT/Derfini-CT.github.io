# Derfini C T — Portfolio Website

A responsive personal portfolio built with plain HTML and CSS.

## Publish with GitHub Pages

1. Create a new public repository named `Derfini-CT.github.io`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your portfolio will be available at:
   `https://derfini-ct.github.io/`

## Before publishing
- Replace the email address if needed.
- Add a professional profile photo if you want one.
- Add screenshots/GIFs from your projects to make the project cards more visual.
- Add your resume PDF link once you have a final resume.
